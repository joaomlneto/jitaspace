Redesigned the Compare tool as a compact table with a header that stays put as you scroll. Item search now works without logging in, and finds items by name, group ("interceptor") or type ID. Attributes are listed by their in-game names with units and icons, grouped by category (Fitting, Shield, Armor, Capacitor, …) in collapsible sections, with the best value in each row highlighted and every value's percentage change against the first item. Unset attributes show their default value, dimmed. You can drag columns to reorder them, pin any item as the baseline, add items from the table itself (focusing the empty box suggests more from the same group), show only the attributes that differ, filter attributes by name, and see Jita buy and sell prices. Popular comparisons are one click away, and item pages have a Compare button. The table works with a keyboard and a screen reader: every value is announced with its attribute, buttons name their item, adding, removing and moving items is announced, and best, worst and default values are marked with icons and text as well as colour. On phones, columns can be reordered from each item's menu. Durations such as capacitor recharge time are now shown in seconds rather than as milliseconds labelled "s".
