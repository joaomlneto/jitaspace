Added type lists — the named item sets the game uses to decide what a rule
applies to, such as which ships may enter a site or what fits in a cargo hold.
Browse and search all of them at **Type Lists** (under Universe), open any list
to see the categories, groups and types it includes and excludes along with
every item it ends up containing, and check an item's new **Type Lists** tab to
see which lists it belongs to and which ones carve it back out.
