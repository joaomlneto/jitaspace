Dogma attribute pages are redesigned: a plain-language description of what the attribute means (AI-generated, labelled as such) leads, next to CCP's own tooltip and note; badges say whether higher is better and whether it is stacking penalised; every effect that changes or reads the attribute is listed in plain language; and the item list, with each item's value, is a searchable table that loads separately, so attributes carried by thousands of items (mass, volume) open quickly.
