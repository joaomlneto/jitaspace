Filters on the redesigned Active Wars overview now persist in the URL. The status, "in combat"/"mutual"/"open for allies" toggles, sort field and direction, and the rows/table view are all reflected in the address bar, so a filtered or sorted view can be shared, bookmarked, and survives a page refresh. This applies to the new overview only — turn it on with the "New Active Wars page" switch in Settings → Experimental.
