Added a **Ship Tree** page and added it to the Universe Explorer menu. It draws EVE's in-game ship tree for any of the 17 factions, the four empires and the pirate and special factions alike, with every hull, its branches, and the point where Omega-only ships begin. Pick a faction from the dropdown (the link keeps your choice, so you can share it), flip the Omega clone switch to see the tree as an Omega pilot does, and scroll or pinch to zoom and drag to pan.

Log in with skill access and the tree lights up with your own skills, so you can see at a glance which ships you can already fly and what each next hull needs. Logged out, it shows the full tree with everything untrained.

The tree is drawn from a snapshot of EVE's static data that ships with the page, so it can trail the live game until the next update.
