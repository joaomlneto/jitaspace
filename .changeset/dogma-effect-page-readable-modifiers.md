Dogma effect pages now describe each modifier in plain language ("Energy Weapon on the ship › Turret Tracking + Tracking Speed Bonus %") instead of raw codes, grouping modifiers that change several attributes or groups the same way, with the raw SDE rows shown underneath. They also show the attributes the effect uses, which effects stop or modify it, and each item's own bonus value, and the item list is now a searchable, paginated table that loads quickly even for effects used by thousands of items.
